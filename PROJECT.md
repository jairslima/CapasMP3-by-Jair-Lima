# CapasMP3-by-Jair-Lima

## Descrição
Recupera capas de álbum ausentes em arquivos MP3 pela API do iTunes e as embute nas tags.

## Stack
Python 3, mutagen, requests.

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python recuperar_capas.py --mode audit --music-dir "D:\Musicas"`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
